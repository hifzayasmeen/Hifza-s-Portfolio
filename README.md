# Hifza Yasmeen — Portfolio

A responsive personal portfolio built with **Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons**.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Create a production build with `npm run build`, then run it with `npm start`.

## Sections

- Hero, about, categorized skills, featured projects, verified project milestones, and contact.
- Accessible mobile navigation, reduced-motion support, responsive layouts, focus states, and subtle scroll reveals.
- Contact form prepares a message in the visitor's email application; it does not store or send form data.
- Page title, description, Open Graph/Twitter metadata, theme color, and favicon are configured for sharing and search.

## Featured project sources

- [Pizza Palace](https://github.com/hifzayasmeen/pizza-delivery-app) — React and Express/MongoDB ordering platform. Its checkout is simulated; the site links to the deployed frontend.
- [EduCore LMS](https://github.com/hifzayasmeen/educore-lms-backend-full) — backend services for role-based learning, course and assignment workflows, certificates, notifications, and analytics. [Live API](https://educore-lms-backend-full-6qi7.vercel.app).

The journey section uses project milestones confirmed by the public repositories. No internship or personal certification details were provided, so none are claimed.

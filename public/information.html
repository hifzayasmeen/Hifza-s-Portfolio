Featured project: RAG pipeline in n8n

n8nLangChain nodesOpenAI EmbeddingsPineconeGPT-4.1-mini

The problem

Teams keep knowledge in documents, but finding an answer means opening files one by one.

How it works

The workflow watches a Google Drive folder. When a new file is uploaded, it extracts the text, creates embeddings with OpenAI and stores them in a Pinecone vector database. An AI agent then uses that vector store as a retrieval tool, so it can answer questions about the stored documents in real time.

What is next

I am now studying how to scale this design for production-level use. The code is on my GitHub repository.
